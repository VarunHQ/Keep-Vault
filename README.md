KeepVault v0.1.0
First MVP release of KeepVault — an offline-first encrypted document wallet for mobile.

Highlights

Encrypted local vault for documents
Main PIN + Decoy PIN (panic mode)
Import and view/share stored documents
Offline sync via encrypted sync package export/import
Welcome flow on app launch
Settings with Light/Dark mode toggle
Change PIN flow for both Main and Decoy vaults with progress indicator

Privacy
Data is stored locally on-device
No cloud backend required for core usage
Sync is user-initiated via encrypted package transfer

Notes
Tunnel/LAN behavior depends on local network setup when running in Expo Go.
This is an MVP release; additional hardening and UX improvements are planned.
